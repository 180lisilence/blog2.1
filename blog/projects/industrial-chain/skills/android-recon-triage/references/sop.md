# 七阶段逆向 SOP

> 本技能覆盖阶段 0–3（只读静态建档）；阶段 4–7 为后续技能范围，此处保留入口与边界，避免静态阶段越界执行。

## 阶段 0 · 立项与红线登记

**输入**：原始 APK/EXE/样本目录。**动作**：建档、定方向、记基线。**台账落点**：`identity.txt`、`方向.txt`。

- 拷贝 `assets/ledger-templates/identity.txt` 填身份区；`方向.txt` 写定位 + a/b/c 三条方向。
- 记原始样本大小/mtime/SHA256（`rahash2 -a sha256`）；原始 APK 与历史解包目录只读不删不改。
- 登记红线：后端域名/IP 不探测；红线样本只归档；凭证只登记存在不转写。
- 方向 a/b/c 与 `待办进度.md` ④ 小节三条一一对应，后续任务引用编号。

## 阶段 1 · 解包与身份识别

**输入**：原始样本。**动作**：解包、反编译、规模统计、身份补全。**台账落点**：`analysis.md` 头部身份区、`待办进度.md` ①。

- APK：`apktool d` 解资源/smali；`jadx -d` 反编译 Java；记 dex 数、smali 类数、jadx java 数、so 清单、assets 规模（计数实读）。
- 身份字段：包名、versionName/versionCode、minSdk/targetSdk、ABI、主 Activity、Application、权限清单。
- 多渠道/多变体：逐变体登记，不合并计数；副本哈希对照记实测值。
- 异常判读：jadx 产出极少 → 先怀疑内存壳/抽 dex（见 protection-map.md），不要误判为样本很小。

## 阶段 2 · 静态穷举

**输入**：解包产物。**动作**：分类型扫描、归集规则与配置、落证据。**台账落点**：`analysis.md` 关键发现、`待办进度.md` ②。

- **字符串**：ASCII/UTF-8 串提取，按授权/卡密/URL/签名/反调试/SDK 标识/路径分组；命中记文件与偏移。
- **Native**：每 so 记架构/类型/NEEDED/导出/导入/JNI_OnLoad/Java_* 符号；符号层证据为准，函数体未反汇编注明。
- **壳/加固**：DIE CLI + UPX 测试 + 特征关键词判定；代理 Application、保护 so、完整性校验线索登记。
- **规则/配置**：Lua/JSON/BSB/配置表/资源包格式与条目规模；自定义容器记 magic 与头字段，未还原部分标【缺口】。
- **网络**：只登记 Manifest/strings/assets 静态可见 scheme、域名、SDK；不主动请求任何端点。
- 扫描片段复用前通读全文；extracted/jadx/build/node_modules 等产物目录不全量递归。

## 阶段 3 · 可修改点分级清单

**输入**：阶段 2 证据。**动作**：逐条定级、登记风险与阻塞。**台账落点**：`可修改点清单.md`、`待办进度.md` ⑥。

- 分级定义见 `ledger-conventions.md` §分级口径；每条含定位/现状/可改法或阻塞原因/影响面与风险。
- A 级静态可直接 patch；B 级仅 UI 展示；C 级服务端/远程保护本地不可绕；D 级需 native/脱壳/容器解包（本轮不做）。
- C/D 级不编造改法；未反汇编 native 条目只记阻塞原因与前置条件。
- 附分级计数汇总表，仍阻塞清单与待办 ③ 未执行项逐条对应。

## 阶段 4 · 深度还原（后续技能 native-unpack）

native 函数级反汇编、VMP/壳脱壳、加密容器解密、脚本提取、规则还原。前置：IDA/Ghidra/动态环境；本阶段产物回填 D 级清单。

## 阶段 5 · 动态验证（后续技能 dynamic-verify）

模拟器/真机环境核对；frida hook 定位校验点；未 root 真机仅装机/logcat；动态结论未实测前标"未动态验证"。**使用模拟器前必须先征得用户同意**（本机多窗口并行）。

## 阶段 6 · 补丁与重打包（后续技能 repack-sign）

smali/Java/Manifest/assets 改写；DEX 校验和重算；回编译、zipalign、签名；dry-run 先行；原始样本备份不删。

## 阶段 7 · 台账回填与交接

静态/动态结论回填 `项目记忆.md`、`待办进度.md`；写 `交接.md`：一句话状态、已完成可复算、断点与 P1/P2/P3、未执行项前置条件、恢复顺序、复现命令、风险注意。

## 阶段间纪律

- 证据标签包内统一一套：【事实】/【推断】/【缺口】（或 已验证/观察假设/未执行），不两套混用。
- 静态通过 ≠ 运行通过；编译/签名/反编译成功不代表功能生效。
- 未执行的命令不写执行结果；未闭环项不写成已闭环。
