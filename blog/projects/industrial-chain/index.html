能力边界

覆盖

  • 样本身份识别：包名 / 版本 / SDK / ABI / 入口 Activity / 权限 / 体积
  • 解包与规模统计：dex / smali / Java / so / assets 计数
  • 静态线索扫描：字符串分组、ELF 符号、壳与加固特征、签名证书线索
  • 可修改点 A/B/C/D 分级台账建档

不做

  • 补丁写回、DEX 校验和重算、重打包 / 对齐 / 重签
  • frida 动态 hook、运行时脱壳 dump、真机观测
  • native 函数级反汇编与伪代码还原
  • 探测样本后端域名 / IP / 卡密端点

证据口径

【事实】文件 / 命令实读

【推断】交叉推断，待动态或解密确认

【缺口】未取得证据、读不到或未执行

  • 版本 / 包名 / 计数 / 体积 / 路径 / 哈希 / 偏移必须来自实读，读不到写"未确认"，禁止编造
  • 未装机 / 未运行 / 未脱壳 / 未 patch 的结论如实标注"未动态验证"

红线

  • 不探测 / 扫描 / 请求任何样本后端域名、IP、卡密端点；被标记为受限的后端域名及其子域禁止任何扫描探测动作
  • 被标记为红线的样本仅做结构归档，不排还原 / 绕过 / 联调
  • 凭证（token、私钥、签名库口令）只登记存在，不读取、不转写、不进对外摘要
  • 原始 APK / 样本 / 历史产物只读；补丁与重打包只在副本或工作区进行

运行环境

Python 3.10+（推荐 3.14）；核心脚本纯标准库，可选第三方依赖 androguard / pyelftools / LIEF / capstone / pefile。缺库时脚本回退外部进程工具或记【缺口】，不崩溃。外部工具（aapt2 / rabin2 / diec / upx）通过环境变量、PATH 或版本通配自动定位，脚本不写死机器专属绝对路径。

本仓库仅覆盖只读静态阶段；动态验证、补丁重打包签名、native 深度还原属后续技能范围。
