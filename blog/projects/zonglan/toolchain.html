常用命令

启动器运行（源码模式）

cd <版本>/源码
python main.py

PyInstaller onedir 打包

python -m PyInstaller --noconfirm --onedir --windowed --name woldvein_launcher \
  --distpath <输出dist> --workpath <输出work> --specpath <输出> main.py

PyInstaller onefile 打包（含数据文件）

python -m PyInstaller --noconfirm --onefile --windowed --name woldvein_launcher \
  --add-data "<数据目录>;02_shuju" \
  --distpath <输出> --workpath <输出> --specpath <输出> main.py

Inno Setup 编译安装包

C:\InnoSetup6\ISCC.exe <脚本.iss>

DLL 编译（普通 / 延迟初始化版）

D:\mingw64\mingw64\bin\gcc.exe -shared -o trainer.dll trainer.c -luser32
D:\mingw64\mingw64\bin\gcc.exe -shared -o trainer_delayed.dll trainer_delayed.c -luser32

启动器 EXE 编译（C++ 静态）

D:\mingw64\mingw64\bin\g++.exe -static -static-libgcc -static-libstdc++ -o Launcher.exe Launcher.cpp -lpsapi

C# 离线修改器编译

C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /out:eastfamily.exe /target:winexe <源码.cs>

Steam API 代理 DLL 生成

python generate_proxy.py  # 生成C和def文件
gcc -shared -o steam_api64.dll steam_api_proxy.c steam_api_proxy.def -luser32

用户偏好约束（必须遵守）

  1. D 盘无中文路径，C 盘不乱动；游戏 storage 目录只读，写文件到指定目录
  2. 每次大改动必须压缩包备份，命名 = YYYYMMDD_HHMMSS_项目改动.zip
  3. 用户是代码小白，注释要清晰易懂；先讲原理再写代码
  4. 工具名 eastfamily；存档时间按北京时间写
  5. 对照表"不要带推理，1 比 1 对应，像小学生查字典"
  6. 执行模式 = 按需确认：普通命令直接运行；删除/覆盖等高风险操作需人工确认
  7. 修改器界面必须内置在游戏画面里（游戏内置 ImGui 面板），不是桌面外部小窗口
  8. 远程投屏时游戏窗口要前台跑 Lua 才执行命令
  9. bat 脚本用纯英文，避免中文编码问题
  10. 用户对需要手动操作的脚本不满意，要求 AI 自己写脚本、自己运行、自己看结果
  11. 处理存档务必先备份，不要轻易删 .boh 文件
