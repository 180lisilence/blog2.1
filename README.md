# 🌍 云客 · 个人博客 & 工作台

> 已部署：https://lizyi.asia
> 当前版本：**云客 2.1 稳定版**

一个自己用的个人博客和工作台，所有内容都需要登录才能看，不公开。

## ✨ 功能

- **博客**：登录后可以看文章、评论
- **项目展示**：自己做的项目列表
- **工作台**：AI 对话、设置
- **登录**：扫码 + 账号密码，多设备登录会互踢
- **安全**：CSP、CSRF、登录失败锁定、IP 限流

## 🛠️ 技术栈

- **后端**：Node.js + Express + MySQL
- **前端**：原生 HTML/CSS/JS，没框架
- **部署**：Nginx + PM2

这个仓库是踩坑备份，记录了之前改UI、加公开功能、回滚稳定版过程中遇到的各种bug和修复，后面重构的时候可以参考。
