# 🌍 云客 · 全门禁个人博客 & 工作台

> 已部署：https://lizyi.asia
> 当前版本：**云客 2.1 稳定门禁版**（2026-11-12）

一个完全私有、全门禁的个人博客与工作台系统。**所有内容均需登录后访问**，无公开页面，无搜索引擎收录，仅授权用户可进入。

## ✨ 功能

- **全门禁架构**：所有页面、资源、API 全部走登录校验，未登录一律跳转登录页
- **个人博客**：仅登录用户可阅读文章、评论、查看项目
- **作品集**：登录后可见项目列表与详情
- **云客工作台**：AI 对话（22+ 模型）、项目管理、设置中心
- **登录系统**：扫码登录 + 账号密码、会话管理、多端互踢、IP 白名单
- **安全加固**：严格 CSP 策略、CSRF 防护、登录锁定、IP 限流、HttpOnly Cookie
- **访问审计**：独立 blog-sentinel 后台（端口 3100），记录所有访问、登录、IP 地理信息

## 🚀 访问说明

- **未登录用户**：打开 https://lizyi.asia 一律跳转到登录页，看不到任何内容
- **授权用户**：登录后可访问全部博客、项目、工作台功能
- **管理员**：访问 https://lizyi.asia:3100 进入访问审计后台

## 🛠️ 技术栈

- **后端**：Node.js + Express + MySQL
- **前端**：原生 HTML/CSS/JS，无框架，严格 CSP 禁止 inline 脚本
- **部署**：Nginx + PM2 + 宝塔面板
- **审计后台**：独立 Koa 服务，端口 3101 本机监听，Nginx 代理 3100 HTTPS
